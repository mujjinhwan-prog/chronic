만성질환 재진 타겟맵 데이터 없음

심평원 Open API 실시간 연동 · 비대면 재진 수요가 클 의원을 지역별로 우선순위화

지수는 어떻게 계산하나요?

공개 데이터에는 의원별 재진율·비대면 실적이 없습니다. 그래서 이 대시보드는 의원마다 실제로 차이가 나는 공개 정보 (진료시간, 내과 전문의, 평가 결과, 개원 연수, 규모)로 점수를 매기고, 지역 안 순위로 등급을 나눕니다.
한 줄 요약: 환자 편의 중심 + 만성질환 관리 역량 + 오래된 동네 내과 = 비대면 재진 영업 우선 대상

지수를 이루는 6가지 지표

현재 가중치가 오른쪽에 표시됩니다. 데이터가 없는 지표는 그 의원 점수에서 빼고 나머지로 다시 100점 환산합니다 (빈칸이 감점이 되지 않음).
① 진료 접근성 (야간·주말 진료)
무엇을 보나
평일 19시 이후 진료하는 날 수, 토요일·일요일 진료 여부
왜 중요한가
환자 편의를 우선하는 의원일수록 비대면 진료 같은 새로운 진료 방식을 받아들일 가능성이 높고, 직장인 만성질환 환자가 많습니다. 의원마다 차이가 커서 변별력이 높은 지표입니다.
점수 계산
야간 진료(평일 하루당 8%, 최대 40%) + 토요일 35% + 일요일 25%
데이터
심평원 의료기관별상세정보서비스 (진료시간)
② 만성질환 관리 역량 (내과·가정의학과 전문의)
무엇을 보나
내과·가정의학과 전문의 수
왜 중요한가
만성질환 재진 환자를 꾸준히 보는 핵심 인력입니다. 일반의 1인 의원과 내과 전문의가 여럿인 의원을 구분합니다.
점수 계산
0명 = 0, 1명 = 60%, 2명 = 85%, 3명 이상 = 만점. 과목별 전문의 정보가 없으면 표시과목과 전문의 총수로 추정합니다.
데이터
심평원 의료기관별상세정보서비스 (과목별 전문의), 병원정보서비스 (전문의 수)
③ 비대면 질환 구성 (Top5)
무엇을 보나
최근 1년 진료량 상위 5개 질병 중 비대면 진료가 가능한 질환의 구성
점수 계산
만성 1개당 50%, 조건부 1개당 15%(최대 45%), 제외 0. 예) 감기·위염·고혈압·비염·장염 = 95%
한계
질병 이름만 오고 환자 수·순위가 없어 보조 지표로만 씁니다. 심평원이 질병정보를 주지 않는 의원은 이 지표를 빼고 계산하며, 목록 전체에 질병정보가 없으면 해당 열을 숨깁니다.
데이터
심평원 병원진료정보조회서비스
④ 만성질환 평가 우수기관
무엇을 보나
심평원 적정성평가 등급: 고혈압·당뇨병(1~5등급), 만성폐쇄성폐질환(1~5등급), 천식(양호 공개)
왜 중요한가
평가 핵심 지표가 방문 지속·처방 지속 환자 비율이라, 재진 환자를 꾸준히 관리한다는 공식 확인입니다.
점수 계산
고혈압·당뇨 등급 최대 75% (1등급 75%, 2등급 56%, 3등급 38%, 4등급 19%, 5등급 0) + COPD 등급 최대 25% + 천식 양호 25%, 합계 최대 100%. 평가 대상이 아닌 의원은 0입니다(평가를 받을 만큼 해당 환자가 많지 않다는 뜻). 1~2등급·양호에 🏅 배지.
데이터
심평원 병원평가정보서비스 API (getHospAsmInfo1). API가 안 될 때는 평가 엑셀을 data 폴더에 올리는 보조 방법도 있습니다.
⑤ 개원 연수
무엇을 보나
개설일로부터 지난 기간
왜 중요한가
오래된 의원일수록 장기 재진 환자군이 쌓여 있습니다.
점수 계산
상한 없이 연속 반영: 25년 = 만점 (예: 5년 = 20%, 15년 = 60%)
데이터
심평원 병원정보서비스 (개설일자)
⑥ 진료 규모 (의사 수)
무엇을 보나
근무 의사 수
점수 계산
1명 43%, 2명 68%, 3명 86%, 4명 이상 만점
데이터
심평원 병원정보서비스

평가 엑셀 받는 방법 (고혈압·당뇨·COPD·천식)

  • 평가결과 보고서(PDF)는 전국 통계라 의원별 등급이 없습니다. 의원별 등급은 상세검색 결과 엑셀로 받아야 합니다.
  • 심평원 누리집 병원평가 상세검색 화면에서 평가항목 만성질환 → 세부항목 고혈압 선택
  • 지역은 비워 두거나(전국) 필요한 시도만 선택 → 검색
  • 조회 결과가 나오면 다운로드(엑셀) 버튼이 활성화됩니다
  • 세부항목 당뇨병으로 바꿔 같은 방법으로 받기
  • 만성폐쇄성폐질환, 천식도 같은 화면에서 세부항목만 바꿔 받기
  • 받은 파일 이름을 eval_hp.xls(고혈압), eval_dm.xls(당뇨병), eval_copd.xls(COPD), eval_ast.xls(천식)으로 바꿔 GitHub 저장소의 data 폴더에 업로드 → 모든 사용자에게 자동 적용 (1년에 한 번 평가 결과가 나오면 같은 이름으로 덮어쓰기)
  • 올리기 전에 '관리자: 파일 미리 확인'에 넣어 보면 몇 곳이 매칭되는지 내 화면에서만 먼저 확인할 수 있습니다.

비대면 적합 질환 기준

  • 포함: 증상이 안정적이고 같은 약을 반복 처방하는 만성질환. 개정안상 일반 비대면진료는 6개월 내 같은 증상으로 대면진료를 받은 의료기관에서 하는 것이 원칙이라, 정기 재진 환자가 핵심 대상입니다.
  • 제외: 개정안에서 비대면 처방이 금지된 마약류·비만치료제가 주로 쓰이는 질환(불면증, 비만, ADHD 등)과 향정신성 약 처방 비중이 높은 질환(불안·공황 등).
  • 조건부: 감기·장염·비염·피부염·불면·우울 등은 비대면 진료가 가능하므로 점수에 포함하되, 초진 7일 처방·단기 진료가 많아 만성질환보다 낮게 반영합니다. 불면·우울은 마약류·향정 약을 제외한 처방만 가능합니다.
  • 복지부가 '오·남용 우려 의약품'을 고시로 추가 지정할 예정이므로, 확정되면 왼쪽 비대면 적합 질환 설정에서 체크를 바꾸면 바로 반영됩니다.

등급 기준 — 지역 안 순위

A 상위 20% · 우선 방문
B 그다음 30% · 관리 대상
C 나머지
- 상세정보 미조회
점수를 정해진 기준점으로 자르지 않고, 지금 선택한 지역 안에서 순위로 등급을 매깁니다. 모두가 높은 점수를 받아도 A는 항상 상위 일부만 됩니다. 비율은 왼쪽 '지수 가중치'에서 바꿀 수 있습니다.

한계 — 꼭 알아두세요

  • 공공데이터에는 의원별 환자 수·재진율·비대면 진료 실적이 없습니다. 이 지수는 "비대면 진료를 할 것이다"의 예측이 아니라 비대면 재진 잠재력이 있는 의원의 영업 우선순위입니다.
  • 원장 성향, 비대면 플랫폼 입점 여부처럼 실제 도입을 좌우하는 요인은 공개 데이터에 없어, MR 현장 확인으로 보완해야 합니다.
  • 상위 5개 질병은 이름만 오고 순위·환자 수가 없어 보조 지표로만 씁니다.

정확도를 높이는 방법

  • MR 현장 확인: A등급 의원 방문 시 만성질환 환자 비중, 비대면 진료 운영 여부를 CRM에 기록 → 몇 달 뒤 점수와 비교해 가중치 조정
  • 사내 처방 데이터 결합: 의원별 만성질환 약 처방 건수가 있다면 가장 직접적인 재진 지표
  • 양호기관 목록 반영: 심평원 평가 엑셀을 올리면 ④ 지표가 채워집니다
  • 지역별 실제 비대면 이용량: 국민건강보험공단에 시군구별 비대면 진료 청구 건수를 공공데이터 제공신청하면 가장 직접적인 지역 지표가 됩니다

만성질환 평가 결과 반영 (고혈압·당뇨·COPD·천식)
자동: ③ 상세정보 조회 때 심평원 병원평가 API에서 고혈압·당뇨병 등급(1~5), COPD 등급(1~5), 천식 양호 여부를 의원마다 받아옵니다. 1~2등급·양호 의원에 🏅 배지가 붙습니다. (data.go.kr '병원평가정보서비스' 활용신청 필요)
평가 데이터 확인 중…
